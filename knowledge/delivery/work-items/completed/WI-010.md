# WI-010 — Actualizar Landing Page y README con la evolución actual de Kaddo

## Current behavior

La landing page y el README fueron creados cuando Kaddo tenía un alcance menor. Desde entonces se incorporaron: Kaddo-native lifecycle, Work Item Refinement, Implementation Handoff, Implementation Evidence, Verification, Admin, External Work Item Integrations, Knowledge Capsules, Kiro integration, self-hosting. La comunicación pública puede no reflejar estas capacidades.

## Target behavior

Landing page y README cuentan la misma historia de producto: Knowledge-Driven Development → Kaddo Lifecycle → Tools/Interfaces → Integrations → Getting Started. Kaddo se posiciona como open-source toolkit para KDD en AI-assisted software engineering.

## Acceptance criteria

- [x] AC-01: Landing y README describen correctamente el estado actual de Kaddo
- [x] AC-02: Kaddo se presenta como open-source toolkit para Knowledge-Driven Development
- [x] AC-03: Ambas superficies presentan el Kaddo-native lifecycle sin depender de OpenSpec
- [x] AC-04: Knowledge, Work Items, Handoff, Evidence, Verification y Learning están representados
- [x] AC-05: CLI, MCP, Admin y Agents aparecen como interfaces del ecosistema
- [x] AC-06: Integraciones y modelo discovery → import → refinement se describen correctamente
- [x] AC-07: Knowledge Capsules aparecen como capacidad actual
- [x] AC-08: Self-hosting (Kaddo builds Kaddo with Kaddo) se comunica
- [x] AC-09: README Quick Start usa únicamente comandos actualmente soportados
- [x] AC-10: Terminología consistente entre landing, README y docs
- [x] AC-11: No quedan referencias a workflows antiguos o features inexistentes
- [x] AC-12: Contenidos y diagramas mantienen comportamiento responsive
- [x] AC-13: Links hacia documentación, GitHub, guides e integraciones funcionan
- [x] AC-14: EN/ES reflejan el mismo estado funcional

## Validation

- New User: puede responder qué es Kaddo, por qué existe, qué es KDD, cómo funciona el lifecycle
- Developer: puede instalar, inicializar, entender WIs y el flujo de implementación
- Existing User: no encuentra contradicciones entre landing, README, docs, CLI, MCP, Admin

## Out of scope

- Landing redesign completo, brand redesign, new logo
- New documentation platform, new capabilities, new integrations
- Telemetry, analytics, SEO strategy, i18n framework changes
