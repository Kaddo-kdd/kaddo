## Project operating modes

Kaddo distinguishes repository maturity from the operating intent of the work. `project.state`
continues to describe maturity, while `project.mode` defaults to `standard` and can be set to
`poc` for a bounded, evidence-led experiment. POC mode uses
`knowledge/delivery/poc.md` for the hypothesis, success criteria, constraints, non-goals,
evidence, and conclusion; it does not require a full roadmap or capability map before an
experiment Work Item can begin.
