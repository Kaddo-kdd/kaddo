## Why Kaddo?

**Your project already has knowledge. It is just scattered.**

In new projects, decisions disappear fast. In pre-AI projects, context was never
prepared for agents. In legacy projects, knowledge often lives in people's heads.

Kaddo brings that knowledge closer to the code and helps keep it alive as the system
changes.

## How it works

Kaddo does not start by creating tasks. It starts by understanding the state of the
project, then builds knowledge progressively before you evolve the code.

<CardGrid>
  <Card title="1 · Initialize" icon="pencil">
    Tell Kaddo if your project is new, pre-AI or legacy, your team size and repo structure.
  </Card>
  <Card title="2 · Scan" icon="magnifier">
    Kaddo deterministically detects stack, structure, dependencies and technical signals.
  </Card>
  <Card title="3 · Understand" icon="open-book">
    Agents help extract capabilities, architecture, risks and open questions. *(upcoming)*
  </Card>
  <Card title="4 · Plan" icon="list-format">
    Kaddo turns the knowledge baseline into a roadmap. *(upcoming)*
  </Card>
  <Card title="5 · Evolve" icon="approve-check">
    Create work items and use Guard to detect when code may drift from knowledge.
  </Card>
</CardGrid>
