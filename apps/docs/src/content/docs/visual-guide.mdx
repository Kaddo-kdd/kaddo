Kaddo Visual Explorer is a visual way to discover the toolkit. Each concept pairs a picture with a
plain explanation, an example and links to the technical documentation — so you can find what is useful
to you without knowing Kaddo beforehand.

These cards are **conceptual illustrations**, not product screenshots, and they describe behavior that
exists today. For the technical Mermaid diagrams of the knowledge loop, see
[Technical diagrams](/visual-guide/diagrams/).

## Keep exploring
