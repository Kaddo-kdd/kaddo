Kaddo Visual Explorer es una forma visual de descubrir el toolkit. Cada concepto une una imagen con una
explicación sencilla, un ejemplo y enlaces a la documentación técnica — para que encuentres lo que te
resulta útil sin conocer Kaddo de antemano.

Estas tarjetas son **ilustraciones conceptuales**, no capturas del producto, y describen comportamiento
que existe hoy. Para los diagramas técnicos Mermaid del knowledge loop, ve a
[Diagramas técnicos](/es/visual-guide/diagrams/).

## Sigue explorando

Abre cualquier tarjeta para leer qué problema resuelve el concepto, un ejemplo concreto, cómo empezar y
a dónde seguir en la documentación.
