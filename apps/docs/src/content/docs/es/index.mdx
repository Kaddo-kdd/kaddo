## ¿Por qué Kaddo?

**Tu código cambia. Tu conocimiento muchas veces no.**

Las decisiones de arquitectura, el contexto de producto, los contratos y los detalles
de implementación suelen vivir en chats, tickets, reuniones o en la cabeza de alguien.
Kaddo mantiene ese conocimiento junto a tu código y ayuda a detectar cuándo puede
quedarse atrás.

<CardGrid stagger>

  <Card title="Guard contra la deriva" icon="approve-check">

  </Card>
  <Card title="Para humanos y agentes" icon="rocket">

  </Card>
</CardGrid>

## Cómo funciona

<CardGrid>
  <Card title="1 · Clasifica" icon="pencil">
    Declara el tipo de cambio y obtén un Nivel de Conocimiento sugerido.
  </Card>
  <Card title="2 · Captura" icon="setting">
    Responde solo las preguntas necesarias para ese nivel — Kaddo crea un work item ligero.
  </Card>
  <Card title="3 · Observa" icon="magnifier">
    Kaddo Guard detecta cuándo un cambio de código puede afectar al conocimiento relacionado.
  </Card>
</CardGrid>
