# Visual Explorer images

Drop concept images here as `<concept-id>.png` (or `.webp`), matching the `image` path declared for each
concept in `apps/docs/src/data/visual-explorer.ts`.

Current slice expects:

- `knowledge-layers.png`
- `work-items.png`
- `knowledge-graph.png`
- `mcp.png`

Guidelines:

- Conceptual illustrations only — never product screenshots or images that present illustrative numbers
  as measured metrics.
- Recommended aspect ratio ~16:10, web-optimized (compressed PNG/WebP).
- Kaddo palette: night blue `#141B2D`, amber `#F4B942`, warm white `#F8F6F0`, soft black `#232122`,
  technical gray `#6B7280`.

Until an image is present, the gallery and fiche render a branded placeholder automatically.
