# Spec: Scan Baseline Artifact

## User Story

As a developer using Kaddo, I want `kaddo scan` to persist a reusable project baseline,
so that humans and LLM agents can use it to understand the project before creating work
items.

## Expected Behavior

When the user runs `kaddo scan`, Kaddo:

1. Analyzes the current project (deterministic signals).
2. Generates `.kaddo/scan.json`.
3. Generates `architecture/inventory.md`.
4. Preserves existing CLI behavior (detection output + config-save prompt).
5. Avoids unsafe overwrites.

## Acceptance Criteria

- [ ] AC1 — After `kaddo scan`, `.kaddo/scan.json` exists with structured scan info.
- [ ] AC2 — After `kaddo scan`, `architecture/inventory.md` exists and is human-readable.
- [ ] AC3 — Missing `.kaddo/` or `architecture/` folders are created safely.
- [ ] AC4 — The command does not call an LLM or require an API key.
- [ ] AC5 — No semantic capability/architecture claims; only suggestions / open questions.
- [ ] AC6 — Markdown overwrite does not silently destroy user-authored content.
- [ ] AC7 — Tests cover JSON generation, markdown generation, and serialization of a minimal scan.

## Edge Cases

- **No package file** — generate a baseline with `unknown`/empty values.
- **Not initialized with Kaddo** — still create required folders; JSON is always written.
- **Empty repository** — generate minimal artifacts.
- **Existing inventory.md** — guard the overwrite (confirm in interactive mode).

## Error Handling

- Unreadable config → treat project context as `unknown` (best-effort, non-fatal).
- File write failure → surface a clear error; do not crash silently.

## Output Examples

`.kaddo/scan.json`:

```json
{
  "version": "1",
  "generatedAt": "2026-01-01T00:00:00.000Z",
  "project": { "state": "pre-ai", "structure": "monorepo", "teamSize": "small" },
  "detected": {
    "languages": ["typescript"],
    "frameworks": ["next"],
    "packageManagers": ["pnpm"],
    "sourceDirectories": ["src"],
    "migrationDirectories": ["supabase/migrations"],
    "contractFiles": ["openapi.yaml"],
    "infrastructureFiles": ["docker-compose.yml"],
    "testDirectories": ["tests"]
  },
  "suggestions": {
    "possibleDomains": ["auth", "payments"],
    "openQuestions": ["Confirm whether the 'payments' domain maps to a code directory."]
  }
}
```

`architecture/inventory.md`:

```markdown
# Project Inventory

> Generated by `kaddo scan`. Deterministic technical baseline — not an interpretation of the system.

## Detected Stack

- Language: typescript
- Framework: next
- Package manager: pnpm

## Source Directories

- src/

## Migrations

- supabase/migrations/

## Contracts

- openapi.yaml

## Possible Domains

- auth
- payments

## Open Questions

- Confirm whether the 'payments' domain maps to a code directory.
```
