# Spec: LLM Context Pack

## User Story

As a Kaddo user, I want to generate a context pack from my project, so that I can use it
with an LLM agent to understand capabilities, architecture, risks and roadmap candidates.

## Expected Behavior

When the user runs `kaddo context`, Kaddo generates `.kaddo/context-pack.md` and
`.kaddo/context-pack.json`, collecting existing Kaddo project context and preparing it for
LLM handoff.

## Acceptance Criteria

- [x] AC1 — Markdown context pack `.kaddo/context-pack.md` is generated, readable and
  suitable to paste into an LLM chat.
- [x] AC2 — JSON context pack `.kaddo/context-pack.json` is generated with structured data.
- [x] AC3 — Project config is included: name, state, team size, structure.
- [x] AC4 — Scan baseline summary is included when `.kaddo/scan.json` exists.
- [x] AC5 — Inventory is referenced/summarized when `architecture/inventory.md` exists.
- [x] AC6 — Work items are included as metadata (not full content).
- [x] AC7 — Missing context is stated clearly when files are absent.
- [x] AC8 — No LLM execution: no API key, no model provider dependency.
- [x] AC9 — State-aware recommendations differ for new / pre-ai / legacy.
- [x] AC10 — Tests cover: generation, missing scan, missing inventory, state-aware
  recommendations, JSON shape, markdown shape.

## Edge Cases

- **Project not initialized** — `.kaddo/config.yml` missing → "Kaddo is not initialized in
  this project. Run `kaddo init` first." and exit non-zero.
- **Scan not run** — `.kaddo/scan.json` missing → still generate; include "Scan baseline
  missing. Run `kaddo scan` for better context.".
- **No work items** — include "No work items found.".
- **Empty knowledge file** — include "No project knowledge summary found yet.".

## Output Example

```
# Kaddo Context Pack

Generated by `kaddo context`.

## Project Metadata

- Name: dotear-web
- State: pre-ai
- Team size: indie
- Structure: monorepo

## Technical Inventory

- Language: typescript
- Framework: next
- Package manager: npm
- Source directories:
  - src

## Current Knowledge

No project knowledge summary found yet.

## Existing Work Items

No work items found.

## Missing Context

- No roadmap baseline found.

## Recommended Agent Handoff

Recommended agents for a pre-AI project:

1. capability-agent
2. architecture-agent
3. roadmap-agent

## Instructions for the LLM

Use this context pack as the project baseline. Do not write code yet. First extract:
system capabilities, architecture notes, risks, open questions, roadmap candidates.
```

## Validation

```bash
pnpm test
pnpm build
kaddo context
```

Confirm: `context-pack.md` exists, `context-pack.json` exists, output is compact, no LLM
is called.
