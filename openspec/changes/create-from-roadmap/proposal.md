# Proposal: Create From Roadmap

## Problem

Kaddo can guide users from a scanned project to a context pack and then to a structured
roadmap generated with the roadmap-agent (VS-009).

However, roadmap candidate work items are still plain text. Users must manually copy
information from `architecture/roadmap.md` into `kaddo create`, which creates friction and
duplicates work. This weakens the flow:

```txt
understanding → roadmap → execution
```

It also breaks a core Kaddo principle: **do not ask again for what the project already
knows.**

## Proposed Change

Extend `kaddo create` to support creating Work Items from roadmap candidate work items.

```bash
kaddo create --from roadmap
# or
kaddo create feature --from roadmap
```

The command reads `architecture/roadmap.md`, detects candidate work items, lets the user
choose one, and prefills the Work Item with relevant roadmap context before writing.

## Why Now

VS-009 standardized the roadmap-agent output. The next step is to turn roadmap candidates
into real Kaddo Work Items, completing the first full Kaddo loop:

```txt
scan → context → agents → roadmap → work item
```

## Scope

- Read `architecture/roadmap.md`.
- Parse roadmap candidate work items (roadmap-agent format).
- Present candidates to the user.
- Create a Work Item from a selected candidate.
- Prefill title, type, knowledge level, expected value and notes when available.
- Reference the roadmap initiative in the Work Item.
- Keep user confirmation/editing before writing.
- Add tests.

## Out of Scope

- Generating the roadmap from the CLI.
- Calling an LLM.
- Creating multiple Work Items at once.
- Parsing arbitrary roadmap formats perfectly.
- Advanced markdown AST parsing if not needed.
- Updating the roadmap status after Work Item creation.
- Integrating with Jira, Linear or GitHub Issues.
- Creating code from the Work Item.

## Expected Value

Users can move from roadmap to execution without retyping context. Kaddo starts converting
product knowledge into actionable, traceable Work Items.

## Risks

- Roadmap parsing may be brittle.
- Roadmaps generated by different LLMs may vary.
- Candidate Work Items may not follow the expected format.
- Users may create Work Items from weak roadmap candidates.

## Success Criteria

A user can run `kaddo create --from roadmap`, select a candidate Work Item from
`architecture/roadmap.md`, and generate a real Work Item under
`architecture/work-items/` with inherited context and traceability to the original
initiative/candidate.
